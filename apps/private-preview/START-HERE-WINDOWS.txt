RENDEZVUE PRIVATE PREVIEW — WINDOWS
====================================

Er is geen lokale Git, Python of Node nodig.

1. Pak het volledige workflow-ZIP-bestand uit.
2. Open de uitgepakte map dist-private-preview.
3. Dubbelklik op Start-Rendezvue-Preview.cmd.
4. Laat het geopende venster actief staan.
5. De browser opent automatisch op http://127.0.0.1:4174/.
6. Sluit het zwarte venster of druk Ctrl+C om de preview te stoppen.

Gebruik uitsluitend gecontroleerde synthetische testaccounts en testgegevens.
De server luistert alleen op de eigen computer (127.0.0.1) en stelt de preview
niet beschikbaar op het lokale netwerk of internet.

Bij de melding dat poort 4174 al in gebruik is: sluit een eerder previewvenster
en dubbelklik opnieuw op Start-Rendezvue-Preview.cmd.
